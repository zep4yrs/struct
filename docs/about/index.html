为什么做这个

自学数据结构和数据库时，最痛苦的不是语法记不住，而是脑子里想象不出过程。看书上的静态图示，看完好像懂了，一做题就错；跟着视频学，看起来很顺，自己写就卡壳。

StructVis 的存在就是为了解决这个问题——把抽象的算法过程变成可交互、可步进、可自己动手试的可视化练习，让自学者不靠老师也能把每个步骤搞明白。

功能全景

学习 · 可视化

  • 48 个数据结构知识点：排序 / 树 / 图 / 线性结构 / 查找 / 动态规划
  • 24 个 MySQL 知识点：查询 / 窗口函数 / 执行计划 / 事务 / 范式等
  • 步进播放器：逐帧、回放、调速、跳步、断点，动画与伪代码同步高亮
  • 动手模式：先预测下一步，再亲手点选验证

练习 · 复习闭环

  • 四类题型：选择 / 填空 / 拖指针 / 补代码，答错立刻给正确答案与解析
  • 错题本自动收集，SRS 间隔复习排期（到期提醒）
  • 每日一题：全站每天同一题，60 秒微学习
  • 章节自测：26 道题按章随机抽题限时作答，成绩回写掌握度

竞技 · 洞察

  • 竞速实验室：30 个排序引擎同屏竞速——21 条经典跑道 + 9 条玩梗跑道（Stalin / Thanos / 量子 Bogo…）
  • 技能图谱：知识点前置依赖网络，规划学习路径
  • 掌握度雷达、学习热力图、一键生成学习报告

讲授 · 分享

  • 投影模式：全屏大字号旁白，键盘翻页，适合课堂大屏
  • 讲授剧本：每步旁白可导入 / 导出 / 重置，配套预录语音朗读
  • 状态分享链接：复制 URL 即恢复当前输入、步数与速度

不是什么

  • 不是通用算法可视化网站（不是给所有人看的炫技 Demo）
  • 不是在线 IDE（不是用来写项目的）
  • 不是题库平台（不刷无解析的选择题）
  • 不是课程平台（不卖课、不做视频）
  • 没有账号体系——进度只存在你的浏览器里，可随时导出备份

是什么

  • 教材对齐的自学辅助工具 — 跟着《数据结构教程》和《数据库技术及应用（MySQL）》的章节走
  • 交互式步进可视化 — 不是看动画，是每一步都可以暂停、可以自己操作、可以试错
  • 即时反馈的练习系统 — 做错了立刻告诉你为什么错，不是只给一个答案
  • 本地进度追踪 — 学到哪了、掌握了多少、错了哪些，全在本地存着，支持导入导出备份

技术栈

  • Svelte 5 + SvelteKit（adapter-static 纯静态部署，GitHub Pages）
  • Tailwind v4 + 自研设计 token（亮 / 暗双主题，AA 对比度基线）
  • Canvas 渲染器插件体系 + GSAP 时间线动画
  • three.js 全站粒子背景（可在设置中关闭）· anime.js 数据动效 · sql.js 浏览器内 SQL 执行
  • Web Speech API 讲授朗读（含预录神经语音回落）
  • Vitest（480+ 单测）+ Playwright（42 条端到端，含视觉截图基线）

数据与隐私

掌握度、错题本、连续学习天数等所有学习数据仅保存在你的浏览器 localStorage 中，不上传任何服务器。进度页提供一键导出 / 导入备份；隐私模式下若写入失败会明确提示，绝不静默丢数据。
