§04 数据库基础

建表练习

CREATE TABLE 定义表的结构：列名、数据类型与约束（主键 / 非空 / 唯一 / 外键）。 选择示例或输入自己的建表语句，系统即时解析并展示表结构，错误会给出教学提示。

建表语句 
CREATE TABLE 学生 (
  学号 INT PRIMARY KEY,
  姓名 VARCHAR(20) NOT NULL,
  专业 VARCHAR(20) NOT NULL,
  入学日期 DATE
)

01
学号

03

NN 非空
04

约束图例
PK 主键：唯一标识一行
NN 非空：不允许 NULL
UQ 唯一：值不重复
FK 外键：引用其他表的主键
