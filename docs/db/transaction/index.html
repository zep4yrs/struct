§08 事务与并发

事务与并发控制

事务是把一组数据库操作打包的原子工作单元，具有四种特性——ACID：原子性（要么全做，要么全不做）、一致性（事务前后完整性约束不变）、隔离性（并发互不干扰）、持久性（提交即永存）。逐步播放三种场景：转账提交、失败回滚、并发丢失更新。
