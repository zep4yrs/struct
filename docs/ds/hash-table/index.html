除留余数法 H(key) = key mod m 把关键字直接映射到槽位，期望一次存取。冲突不可避免： 线性探测沿后继槽位找空位（开放定址），链地址法则把同义词挂成链表。装填因子 α = n/m 决定冲突频率，也决定平均查找长度。
