数据结构与算法

李春葆《数据结构教程》第5版配套自学练习。每个知识点都有步进可视化 + 交互式练习， 卡片底部的进度条反映你的掌握度。

快速排序

交互式

选一个基准，比它小的扔左边、大的扔右边，再对两边重复

二叉树遍历

交互式

按不同顺序访问每个节点：先根、中根、后根，或一层层扫

单链表

交互式

一串用指针连起来的节点，插删不用挪位置，找元素只能顺着爬

栈和队列

交互式

栈只能从顶进出（后进先出），队列一头进另一头出（先进先出）

冒泡排序

交互式

相邻两个比一比，大的往后换，每一轮最大的数就冒到了末尾

直接插入排序

交互式

像整理扑克牌：每张新牌插进前面已经排好的部分里

简单选择排序

交互式

每轮从剩下的里挑最小的放到前面，交换次数最少的排序

归并排序

交互式

两个有序表合成一个有序表：从单个元素开始两两合并到整体

堆排序

交互式

把数组看成一棵完全二叉树，每次取走堆顶，再把剩余调整成堆

希尔排序

交互式

按间隔分组各自做插入排序，间隔逐轮缩小到 1

基数排序

交互式

不比大小，按个位、十位……逐位「分发—收集」

计数排序

交互式

数每个值出现了几次，再按顺序回填——值的范围小才划算

图的存储

交互式

邻接矩阵一行看出谁连谁，邻接表省空间但查边要遍历

图的遍历

交互式

BFS 一层层扩散（用队列），DFS 一条路走到黑再回头（用栈/递归）

最小生成树

交互式

用最小的总边权把所有点连起来：Prim 逐点扩张，Kruskal 逐边挑选

最短路径

交互式

Dijkstra：每次把离起点最近的点定下来，再用它松弛邻居

拓扑排序

交互式

每次拿走入度为 0 的点——课程先修顺序就是这么排的

关键路径

交互式

AOE 网里耗时最长的那条路，决定整个工程的最短工期

串的模式匹配（KMP）

交互式

主串指针不回退，失配时模式串按 next 数组跳到该去的位置

Sunday 匹配

交互式

失配时看主串参与匹配段后面那一格的字符，按偏移表大步跳

最长回文子串

交互式

插分隔符后利用已算出的回文半径对称加速，线性找最长回文

二叉搜索树

交互式

左子树都比它小、右子树都比它大，查找时每次决定走左还是走右

哈夫曼树

交互式

每次取权值最小的两棵树合并——权值越大离根越近

AVL 树

交互式

任何节点左右子树高度差不超过 1，插入后旋转恢复平衡

二分查找

交互式

每次与中间元素比一下，查找范围直接砍一半

哈希表

交互式

用函数直接算出存储位置，撞车了就按规则另找位置

哈希表 · 线性探测

交互式

冲突就顺次往后挪一格找空位——堆在一起会越探越远

红黑树

交互式

用红黑两色维持「近似平衡」，插入删除最多转三次就稳

Trie 字典树

交互式

按字符逐层分叉，公共前缀只存一份

A* 寻路

交互式

优先扩展 f=g+h 最小的点，h 是到终点的估计距离

并查集

交互式

每个集合一棵树，find 找到代表元素，union 把两棵树合并

Tarjan 强连通分量

交互式

一次 DFS 用 dfn/low 两个数，把「互相可达」的点打包成组

割点检测

交互式

删掉它图就断开的点；DFS 里用 low 与 dfn 比出来

LCA 最近公共祖先

交互式

倍增预处理每个点的 2^k 级祖先，查询时两点同步上跳

Bellman-Ford 最短路

交互式

所有边松弛 n-1 轮，能处理负权；再松弛还能动就有负环

最大流 Edmonds-Karp

交互式

反复找从源点到汇点的增广路推流量，直到一条都找不到

二分图判定

交互式

染色法：相邻点颜色必须相反，染出冲突就不是二分图

B+ 树插入

交互式

多路平衡树：叶子满了就分裂，键上提到父层——数据库索引的地基

单调栈

交互式

栈里保持单调，新元素把挡路的都弹出去——每个元素只进出一次

跳表 Skip List

交互式

给有序链表加多层快速通道，查找像走高架桥

树状数组 Fenwick Tree

交互式

下标按 lowbit 分层管理，前缀和与单点更新都是 O(log n)

LRU 缓存

交互式

哈希表负责定位、双向链表管新旧顺序，淘汰永远从尾部走

N 皇后回溯

交互式

一行放一个皇后，列和对角线冲突就回退换位置

0-1 背包

交互式

每件东西选或不选：f[i][j] = max(不选它, 选它)

最长公共子序列

交互式

字符相等取左上 +1，否则取上、左中较大的，表格回溯出序列

最长递增子序列 LIS

交互式

f[i] = 前面比它小的 f 里最大的 +1；贪心加二分能到 O(n log n)

编辑距离

交互式

一个词最少几步（增/删/改一个字符）能变成另一个词

矩阵链乘法

交互式

加括号决定先算谁，区间 DP 枚举每个区间的最优切分点

完全背包

交互式

每件东西可以拿无限件，一维数组正序循环就能转移
