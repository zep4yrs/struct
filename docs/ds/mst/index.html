最小生成树

用 n-1 条边连通全部 n 个顶点且总权最小的树，就是最小生成树（MST）。Prim 从一个顶点 逐步扩张树，Kruskal 把边按权从小到大挑选、成环即弃。观察边权数字与颜色变化，对比两种 算法的贪心策略。
