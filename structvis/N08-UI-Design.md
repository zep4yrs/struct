## §01 设计目标与原则

1. **清晰优先于炫技**：教学工具的第一性是"一眼看懂在发生什么"，不是视觉花活。
2. **状态永远可见**：当前步、对比结果、对错、进度都要即时、显式地反馈。
3. **键盘即一等公民**：所有操作可键盘完成（演示态尤其重要，老师不碰鼠标）。
4. **不依赖颜色 alone**：状态除颜色外必有图标/文字/形状辅助（无障碍硬要求）。
5. **动效服务于理解**：动画有开始/暂停/单步/减速，且尊重 `prefers-reduced-motion`。
6. **暗色与亮色双主题**：自学夜读 + 课堂投影两种场景都舒适。

## §02 设计系统（Design Tokens）

### 2.1 色彩（Light / Dark 双主题）

**Light**
- 背景：primary `#FFFFFF` / secondary `#F8FAFC` / tertiary `#F1F5F9`
- 主色 primary：`#2563EB`（hover `#1D4ED8`）—— 学术蓝，稳定可信
- 强调 accent（步进/当前操作高亮）：`#F59E0B`（琥珀，仅用于"此刻在动的地方"）
- 语义：success `#16A34A` / warning `#D97706` / danger `#DC2626` / info `#2563EB`
- 文本：primary `#0F172A` / secondary `#475569` / tertiary `#94A3B8`
- 边框：`#E2E8F0`（0.5px 细线为主）

**Dark**（投影/夜读）
- 背景：primary `#0F172A` / secondary `#1E293B` / tertiary `#334155`
- 主色/强调/语义同上加亮一档；文本 primary `#F8FAFC` / secondary `#CBD5E1` / tertiary `#94A3B8`
- 边框：`#334155`

> 所有前景/背景对比 ≥ 4.5:1（AA）；accent 仅作强调不承载唯一信息。

### 2.2 字体排印

- 界面：Inter / PingFang SC，字重仅 400 / 500 两档
- 等宽（SQL、伪代码、复杂度）：JetBrains Mono
- 字号阶梯：display 32 / h1 24 / h2 20 / h3 16 / body 14 / small 12 / caption 11
- 行高：标题 1.2 / 正文 1.6

### 2.3 间距与圆角（8pt 网格）

- 间距：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
- 圆角：sm 6 / md 10 / lg 14 / xl 16 / full 999
- 卡片：白底（dark 为 surface）、0.5px 细边框、radius-lg、padding 16–20

### 2.4 阴影与层级

- 默认无投影（flat）；仅焦点环用 `0 0 0 2px` 主色描边表达"当前聚焦"。
- 浮层（下拉/弹窗）用 1px 边框 + 极轻投影区分层级，绝不用重阴影。

### 2.5 组件库选型

- **Radix UI + shadcn/ui 风格**：Radix 提供无障碍原语（focus trap、aria、键盘），shadcn 提供可改源码的像素级控制——不黑盒、可审计。
- 图标：lucide-react（线性、统一描边）。
- 动画：framer-motion（统一受 `prefers-reduced-motion` 门控）。
- 表单/输入：裸标签 + Radix，统一 focus ring。

## §03 信息架构与导航

```
顶部栏    [Logo] [全局搜索 / 深链入口]            [主题切换] [进度]
侧边栏    数据结构 | 数据库 | 我的进度 | 演示剧本
主区      / 首页(内容地图)
         /ds/:topic   算法可视化工作台（三视图）
         /db/sql      SQL 练习场
         /db/:topic   索引 / 事务 / 连接 等
         /demo/:id    演示投影态
```

- 深链直达：`/ds/quick-sort`、`/db/sql` 等，支持"作业卡住粘链接直接跳"。
- 全局搜索：按主题名/关键词跳转到对应可视化。

## §04 核心界面规范

### 4.1 首页 / 内容地图
- 顶部：总进度环（已掌握主题数 / 总主题数）。
- "本周推荐"：按学期进度提示（如"本周：链表 / SQL 基础"）。
- 主题卡片网格：数据结构（线性/树/图/哈希/排序/查找）、数据库（关系模型/SQL/索引/事务/范式/连接）。
- 占位主题明确标"规划中"，空状态友好，不出现死链空壳。

### 4.2 算法可视化工作台（三视图，对应 §11 改进一）
- **左 · 结构可视化（Canvas）**：数组/树/图随步进渲染，当前操作元素用 accent 高亮，已归位用 success 绿，pivot 用 danger 红（且旁附文字标签，不靠颜色 alone）。
- **中 · 伪代码 + 状态（同步高亮）**：当前执行行高亮，指针/索引变量实时显示，与左图严格同步。
- **右 · 控制条**：单步 ← / ▶ 播放 / →、速度滑块、**自定义数据输入（what-if）**、"构建式练习"入口（暂停后补全下一步/拖出指针/写当前数组状态）。
- **底 · 状态栏**：`步骤 x / n — <一句话说明>`，并用 `aria-live` 播报给屏幕阅读器。

### 4.3 SQL 执行工作台
- 左：SQL 编辑器（等宽、语法高亮、示例按钮）。
- 右上：结果表（真实 sql.js 执行）。
- 右下：执行计划树（`EXPLAIN QUERY PLAN` 解析为可读树，SCAN/SEARCH/USE TEMP B-TREE 等节点带说明）。
- 运行后即时显示耗时、命中索引提示。

### 4.4 演示投影态（对应 §11 改进三）
- 大字号、隐藏侧栏与控制杂项，纯键盘 ← → 步进。
- 旁白/答案可一键隐藏或显示（讲时藏、复盘时显）。
- 讲授剧本：预设步骤序列 + 旁白文本，一键顺序播放；排练模式在家走一遍存剧本。
- 离线优先、秒开、出错优雅降级（WASM 失败显示静态图，不白屏）。

### 4.5 进度与掌握度（对应 §11 改进二）
- 每主题做完练习显示掌握度条（全本地）。
- 成就徽章（纯本地），可导出分享图。
- 错题本、学期进度对齐提示。

## §05 无障碍规范（WCAG 2.1 AA）

- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1。
- 键盘：所有交互可 Tab 到达、有可见焦点环；演示态纯键盘可完整操作。
- 屏幕阅读器：Canvas 动画提供文本等价 + `aria-live` 逐步播报；语义 HTML（header/main/nav/section）；所有图标按钮有 `aria-label`。
- 动效：全局监听 `prefers-reduced-motion`，自动转为静态分步或瞬切。
- 不依赖颜色：状态必配图标/文字（如 pivot 红块旁标"pivot"）。
- 跳转链接：主区前有"跳到内容"链接，便于读屏用户。
