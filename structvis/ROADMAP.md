## 竞速实验室 · 趣味算法跑道

在现有 8 条严肃跑道（快排/归并/冒泡/选择/插入/堆/希尔/基数）之外，增加"趣味算法"分组跑道：

| 算法                      | 玩法                                                      | 竞速效果                         |
| ------------------------- | --------------------------------------------------------- | -------------------------------- |
| 灭霸排序（Thanos Sort）   | 随机删除一半元素；若仍无序继续删一半，直到有序或只剩 1 个 | 瞬间"减半"，结果随机、不保证有序 |
| 斯大林排序（Stalin Sort） | 从左到右扫描，逆序元素直接"枪毙"（删除），剩余天然有序    | O(n) 秒完成，但丢弃大量元素      |
| 猴子排序（Bogo Sort）     | 随机打乱，检查有序？无序继续打乱                          | 期望 O(n·n!)，几乎永远跑不完     |

设计要点：

- 与严肃算法同屏竞速，突出"复杂度 vs 正确性"的对照教学价值
- 引擎需保证步骤数有限（斯大林 = 一次扫描；灭霸 = 至多 log₂n 轮；猴子 = 打乱步数设上限并在 complete 文案说明"期望无限"）
- 跑道卡片加"趣味"徽标区分；完成后结果可能未排序（灭霸），需在结果区给出说明文案

## 竞速实验室 · 趣味算法跑道（扩充）

在第一版（灭霸/斯大林/猴子）基础上追加：

| 算法                               | 玩法                               | 竞速效果                                     |
| ---------------------------------- | ---------------------------------- | -------------------------------------------- |
| 睡眠排序（Sleep Sort）             | 每个元素"睡"多少值就多久后醒来报到 | 输出顺序 = 值升序，但总耗时 = 最大值         |
| 量子猴排（Quantum Bogo）           | "同时存在于所有排列，一观测就有序" | 一步到位（纯段子，步骤极少）                 |
| 智能设计排序（Intelligent Design） | 宣称"它本来就是有序的"，不解释     | 一步完成，结果 = 原数组                      |
| 拖延排序（Procrastination）        | 永远不执行（先放着，明天再说）     | 永不冲线（步骤 = 1，但总时长设为无穷大占位） |
| 地精排序（Gnome Sort）             | 花盆故事：往前插、撞了就回退一步   | 真实算法但过程滑稽，可视化有趣               |
| 煎饼排序（Pancake Sort）           | 只允许翻转前缀，翻出最大值         | 翻转动画，真实算法 + 趣味                    |
| 博佐排序（Bozo Sort）              | 随机交换两个元素，检查有序         | 比猴子快一点点的"随机疗法"                   |
| 最差排序（Worst Sort）             | 暴力枚举所有排列找有序的那个       | 确定性 O(n!)，必跑不完（设上限）             |

## 竞速实验室 · 真实排序算法跑道（扩充 · 有真正意义）

现有 8 条严肃跑道（快排/归并/冒泡/选择/插入/堆/希尔/基数）。以下为可新增的**真实排序算法**（复杂度有教学意义、适合可视化 + 竞速）：

| 算法                        | 思想                                       | 复杂度            | 竞速看点                               |
| --------------------------- | ------------------------------------------ | ----------------- | -------------------------------------- |
| 鸡尾酒排序（Cocktail Sort） | 双向冒泡，每轮两端同时排定                 | O(n²)             | 比冒泡快一倍的"改良版"，走势对称       |
| 梳排序（Comb Sort）         | 冒泡 + 递减间隙，间隙 1.3 倍收缩           | 平均 O(n²/2^p)    | 大间隙快速"梳"掉乱序                   |
| 计数排序（Counting Sort）   | 非比较排序，按值域统计频次回填             | O(n+k)            | 1..n 互异数据下近乎 O(n)，碾压比较排序 |
| 桶排序（Bucket Sort）       | 分桶 → 桶内排序 → 拼接                     | 平均 O(n+k)       | 与基数排序对照"分而治之"               |
| 奇偶排序（Odd-Even Sort）   | 奇偶下标交替比较交换（并行冒泡）           | O(n²)             | 网络化交换节奏，适合展示并行思想       |
| 圈排序（Cycle Sort）        | 每个元素直接放到最终位置，最小写入次数     | O(n²) 写 O(n)     | 与选择排序对比"写次数"                 |
| 耐心排序（Patience Sort）   | 扑克牌接龙堆 + 二分定位，求 LIS            | O(n log n)        | 视觉新颖，关联 LIS 教学                |
| 双调排序（Bitonic Sort）    | 双调序列归并，比较网络（GPU 排序）         | O(n log²n)        | 网络级并行结构，理论价值高             |
| 三路快排（3-Way QuickSort） | 三分区：小于/等于/大于基准（重复元素优化） | 平均 O(n log n)   | 与快排对照，重复数据优势明显           |
| 双轴快排（Dual-Pivot）      | 两个基准三区间（JDK 默认排序）             | 平均 O(n log n)   | 生产级算法，工程意义                   |
| 自然归并（Natural Merge）   | 识别天然有序段直接合并                     | O(n log n) 自适应 | 对近似有序数据极快，自适应演示         |
| 斯托奇排序（Stooge Sort）   | 递归三分：前 2/3、后 2/3、前 2/3           | O(n^2.7)          | 递归搞笑但真实，"最慢递归之一"         |

设计要点：

- 与现有 8 条同屏竞速，按复杂度分色标注（O(n²) 深色 / O(n log n) 亮色 / 非比较特殊色）
- 计数/桶排序依赖值域，竞速数据（1..n 互异乱序）天然适配，无需改数据生成
- 跑道较多时可分组：O(n²) 组、O(n log n) 组、非比较组、趣味组，避免一眼看不过来
